## How I work

**Discovery first.** Every system here started as a conversation with someone describing a problem badly, because that is how problems arrive. The work is turning that into a scope that can be built.

**Ship small, ship early.** Prototypes in days rather than quarters, in front of the person who asked, before the architecture is precious.

**Build for handover.** If a system only runs while I am in the room, it has failed. Documentation, SOPs and training are part of delivery, not an afterthought.

**Evaluate honestly.** LLM output gets stress-tested against real failures, not happy paths. Prompts and agent design iterate against what actually breaks.
